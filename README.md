# ExcelSearch

ExcelSearch 是一个完全在本机运行的 Excel 内容搜索程序。把 Excel 文件或文件夹添加到程序后，即使忘记内容在哪个文件里，也可以通过工厂代码、物料编号、物料名称等片段快速找到对应的文件、工作表和行。

- Windows 是主要使用平台，最终用户不需要安装 Python、Excel 插件或数据库。
- macOS 支持开发、测试和直接运行。
- Excel 内容和搜索索引只保存在本机，不会上传到网络。
- 程序只读取 Excel，不会修改或删除原始文件。

## 下载

请从 [GitHub Releases](https://github.com/huantingdream/ExcelSearch/releases/latest) 下载最新版本。

- 普通 Windows 用户：下载 `ExcelSearch-Setup.exe`，双击并按向导安装。
- 不想安装：下载 `ExcelSearch-Windows-x64.zip`，完整解压后双击 `ExcelSearch.exe`。

便携版不能只复制其中一个 `ExcelSearch.exe`，旁边的运行文件也必须保留。如果需要只发送一个文件给别人，请发送安装包。

## 主要功能

### 搜索 A、B、C、D 四列

每个工作表的 A、B、C、D 四列都会进入搜索索引，常见用途包括：

- A 列：工厂代码，例如 `HZ015`。
- B 列：物料编号，例如 `B20103S16`。
- C 列：物料名称，例如 `美式排插 四孔长方形 0.9M`。
- D 列：其他补充内容。

支持中文、英文、数字和混合内容，也支持只输入记得的一部分。英文字母不区分大小写，例如 `type-c` 可以匹配 `TYPE-C`。

E 列及之后的内容不会参与搜索。工作表中的图片、图表、嵌入对象和图片里的文字也不会被识别或索引。

### 多关键词和跨列搜索

多个关键词用空格分隔，采用“全部包含”规则，而且关键词可以来自不同列。

例如输入：

```text
HZ015 四孔 墨西哥
```

程序只显示同一行 A–D 四列合并后同时包含 `HZ015`、`四孔`、`墨西哥` 的结果。关键词不需要位于同一个单元格，但必须位于同一个工作表的同一行。

### 添加 Excel 文件

“添加 Excel 文件”用于选择一个或多个具体文件：

1. 点击“添加 Excel 文件”。
2. 选择 `.xlsx`、`.xlsm` 或 `.xls` 文件。
3. 程序读取 A–D 列并建立本地索引。
4. 索引完成后即可搜索。

重复添加同一个且没有发生变化的文件时，程序会跳过，不会产生重复结果。

### 添加文件夹

“添加文件夹”适合一次管理大量 Excel：

- 递归扫描所选文件夹及其子文件夹。
- 自动查找 `.xlsx`、`.xlsm` 和 `.xls` 文件。
- 自动忽略以 `~$` 开头的 Excel 临时文件。
- 多个文件使用 2–4 个工作线程并行读取，提高批量索引速度。
- 数据库仍然顺序写入，避免并发写入导致索引损坏。
- 解析结果使用磁盘缓冲，避免大量工作簿同时占用过多内存。
- 损坏、加密或无权读取的单个文件只会单独报错，不会中断其他文件。

程序会记住所添加的文件和文件夹，之后可以使用“刷新索引”检查变化。

### 刷新索引

“刷新索引”用于让搜索结果与之前添加的 Excel 文件和文件夹保持一致。点击后会：

- 重新扫描之前添加过的文件夹。
- 为文件夹中新增加的 Excel 建立索引。
- 根据文件大小和修改时间识别已经变化的文件，并重新索引。
- 跳过没有变化的文件，因此通常比全部重建更快。
- 标记已经被删除或移动的文件，避免继续显示无效结果。
- 软件升级导致索引格式变化时，自动更新旧索引。

刷新索引不会修改 Excel，也不会无条件重建所有文件。

适合点击“刷新索引”的情况：

- 修改并保存了某个 Excel。
- 向已添加的文件夹中放入了新 Excel。
- 删除、移动或替换了某些 Excel。
- 希望确认当前搜索结果与磁盘文件一致。

### 清空索引

“清空索引”只删除程序生成的本地搜索索引：

- 不会删除、移动或修改任何原始 Excel。
- 不会忘记之前添加的文件和文件夹位置。
- 清空后暂时搜索不到内容。
- 清空后点击“刷新索引”，可以从之前添加的位置重新建立全部索引。

它适合在索引异常、需要彻底重建，或者不希望本机继续保留可搜索文本时使用。

## 搜索结果说明

每条结果会显示：

- Excel 文件名。
- 工作表名称。
- C、D 单元格位置和所在行，例如 `C27 / D27`。
- A 列工厂代码。
- B 列物料编号。
- C 列物料名称。
- D 列补充内容。
- 文件最后修改时间。
- 文件完整路径。

搜索词会在 A、B、C、D 列中高亮显示。一次最多显示 500 条结果，避免结果过多导致界面卡顿。

结果支持以下操作：

- 双击结果：使用系统默认的 Excel 程序打开原始文件。
- 右键选择“打开 Excel”：打开原始文件。
- 右键选择“在文件管理器中显示”：在 Windows 文件资源管理器或 macOS Finder 中定位文件。
- 右键选择“复制文件路径”：复制完整路径。

程序会告诉你命中的工作表和行号，但当前版本不会自动控制 Excel 跳转到对应单元格。

## 推荐使用流程

1. 首次使用时点击“添加文件夹”，选择存放 Excel 的总目录。
2. 等待索引完成。
3. 输入记得的任意片段进行搜索。
4. 双击正确结果打开原始 Excel。
5. Excel 内容或文件夹发生变化后，点击“刷新索引”。
6. 只有需要彻底重建时才使用“清空索引”。

## 支持范围与限制

支持的文件格式：

- `.xlsx`
- `.xlsm`
- `.xls`

当前限制：

- 只搜索 A、B、C、D 四列。
- 不搜索图片、图片中的文字、图表、批注、嵌入对象或宏代码。
- 不支持破解或读取受密码保护的工作簿。
- 公式单元格读取 Excel 文件中已经保存的计算结果；如果文件没有保存计算结果，可能无法搜索到该公式的显示值。
- 程序不会编辑 Excel，也不会删除、移动或重命名原始文件。

## 本地索引位置

索引数据库是可重新生成的本地文件，不包含图片：

- Windows：`%LOCALAPPDATA%\ExcelSearch\index.db`
- macOS：`~/Library/Application Support/ExcelSearch/index.db`

卸载程序不会删除原始 Excel。

## 开发与构建

项目使用 Python 3.11+、PySide6、openpyxl、xlrd、SQLite FTS5、PyInstaller 和 Inno Setup，CI 会同时在 Windows 和 macOS 上运行测试。

### Windows 构建

安装 64 位 Python 3.12 和 [Inno Setup 6](https://jrsoftware.org/isinfo.php)，然后在 PowerShell 中运行：

```powershell
.\scripts\build_windows.ps1
```

成品会生成在 `release` 目录：

- `ExcelSearch-Setup.exe`
- `ExcelSearch-Windows-x64.zip`

### macOS 开发运行

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
python -m excel_search
```

运行测试：

```bash
python -m pytest
```

macOS 不能直接交叉生成可靠的 Windows PyInstaller 程序。推送到 GitHub 后，仓库的 `Test and build` 工作流会在 Windows 环境生成安装包和便携版。
